Инструкция пользователя
Чтобы работать с программой необходимо нажать:
•	R – для выбора русского языка.
•	E – для выбора английского языка.
На ввод слов дается 60 секунд. При правильно введенном слове, другое слово для ввода появляется автоматически. Когда время закончится, пользователь увидит количество правильно введенных слов и тренажер перезапустится. Удачи!
